# nftscalping — скальпер по стакану (Bybit, 24/7 на Railway)

- Сигнал только из стакана и ленты сделок, без свечей: дисбаланс заявок в окне `depthPct` % от цены (`imb`) и поток агрессивных сделок за `flowSec` с (`flow`), `confirm` раз подряд, спред ≤ `maxSpread` %.
- Вход и выход — только лимитки-мейкеры (PostOnly) с догоном, маркета нет. Тейк лимиткой +`tp` %, трейлинг (с +`act` %, откат `trail` %, не хуже +`minProfit` %), выход при развороте стакана, риск 1:`slRR`.
- Нейросеть (fal.ai, `FAL_KEY`) выбирает монеты и сторону по данным стакана и подстраивает параметры в рамках.
- 📈 Фильтр 5-мин прогноза (`predictor.js`): стакан, лента/CVD, OI, фандинг, ликвидации, киты по WebSocket Bybit → онлайн-модель. Вход только если P(цена через 5 мин в сторону сделки) ≥ `predMin` %; каждый прогноз сверяется с ценой через 5 мин — точность видна в панели.
- По умолчанию симуляция на живом стакане; галочка Live — реальная торговля. Ордера бота помечены `mb_`.

Переменные Railway: `BYBIT_API_KEY`, `BYBIT_API_SECRET`, `UI_PASSWORD`, `FAL_KEY`. Volume на `/data`.

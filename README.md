# nftscalping — маркет-мейкер на пробоях (Bybit, 24/7 на Railway)

- Раз в минуту выбирает до `maxCoins` самых волатильных USDT-перпов (без акций/ETF/металлов/стейблов).
- У каждой монеты коридор последних `boxBars` минут: условный BUY над ним, условный SELL под ним; заявки переставляются вслед за ценой.
- Только лимитки-мейкеры (PostOnly): вход на ретесте пробоя (лимитка на уровне или `pull` % за ценой, подтягивается за ценой), тейк лимиткой +`tp` %, трейлинг и стоп — выход лимиткой, догоняющей цену. Аварийный стоп `hardSl` % на бирже — страховка.
- Одна позиция на монету, пауза после выхода, защита дня (−`dayStop` % — новые входы не ставятся).
- По умолчанию симуляция на живых ценах; галочка Live — реальная торговля. Ордера бота помечены `mb_`.

Переменные Railway: `BYBIT_API_KEY`, `BYBIT_API_SECRET`, `UI_PASSWORD`, (опц.) `BYBIT_ENV=testnet`. Volume на `/data`.
